# NeuroStation 独立实时脑电指令应用

本程序持续读取真实 OpenBCI Cyton 脑电，调用已训练、哈希锁定的三分类模型，直接显示并输出指令。小球页面及运行代码已移除。历史分析记录保留。

## 启动与操作

可以双击项目根目录的 `启动实时脑电指令.cmd`，也可在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_realtime_commands.ps1
```

启动器先检查正式配置、采集依赖和锁定模型。只检查环境可附加 `-CheckOnly`。界面使用 `.venv`，模型子进程使用 `.venv-ml-gpu`；默认 CPU，小模型也可手动选择 CUDA。打开界面不会连接头盔或开始闪烁。

1. 关闭其他程序对同一 Cyton 串口的采集占用，选择串口（可用 AUTO）、完整通道配置、记录目录和 60 Hz 刺激屏幕。
2. 实际检查 CH1–8 对应 Fp1、Fp2、C3、C4、P7、P8、O1、O2，参考、BIAS、地线连接后勾选确认。配置文件本身不能证明头盔佩戴位置正确。
3. 阅读界面光敏风险提示；愿意参与刺激测试时勾选确认。随时按 Esc 或停止键中止。
4. 点击设备预检，等待真实握手、采样检查与模型加载完成。失败、降级、取消的预检不允许采集；warning 保留具体质量问题供查看。预检有效期 300 秒，配置或端口变化需重做。
5. 点击屏幕校对。全屏显示静态灰色目标，记录实际交换帧时序；需原生显示、真实 OpenGL 上下文、60 Hz 与 vSync。offscreen/软件渲染不能产生有效通过记录。界面交换帧测量不等同于光电传感器测得的物理显示延迟。
6. 校对通过后，在同一目标窗口按 Enter/空格开始。采集握手成功才开始三个目标刺激。注视目标，保持佩戴和坐姿稳定。
7. 开始刺激后先舍弃 1 秒启动过渡数据，再积累完整 5 秒连续脑电，之后每 1 秒更新一次。切换注视目标时，最近 5 秒窗口包含此前注视，输出会有延迟；这不是瞬时任意意图识别。
8. 按 Esc 或停止。立即输出 UNKNOWN，停止刺激，释放设备，保存记录。下次采集创建新会话，重新预检。

## 指令含义

| 注视目标 | 频率 | 输出 |
|---|---:|---|
| 左侧 | 10 Hz | MOVE_LEFT |
| 中央 | 15 Hz | SELECT |
| 右侧 | 12 Hz | MOVE_RIGHT |
| 质量异常、拒识、断流、超时、中止 | — | UNKNOWN |

当前模型识别三种视觉刺激诱发的脑电模式。它尚未训练静息类别，UNKNOWN 是质量与置信门控结果，不能保证准确识别休息或任意其他脑电状态。程序不会把屏幕目标、期待指令或刺激标签送进模型。

## 输出接口

每次推理后的指令写入当前会话 `commands.ndjson`，也输出到进程 stdout。可勾选发送到 **127.0.0.1:8765 / UDP**；默认关闭。每个数据报是一行 UTF-8 JSON。UDP 无到达保证，接收方应校验会话与递增事件号、忽略过期或乱序消息，并在 1500 ms 未收到有效续期时保持停止。SELECT 每个接受窗口都可能重复出现，接收方如需一次性动作应实现边沿/冷却策略。

指令字段包含 `command`、`accepted`、`reason`、会话 ID、请求/代次关联信息、原始概率与 OOD 结果、样本范围、推理延迟、UTC/单调时钟时间、有效期。UNKNOWN 的有效期为 0；停止/断流会发送 UNKNOWN。`executed=false` 表示程序输出了消息，没有执行操作系统快捷键或外部设备动作。

```json
{"type":"command","command":"MOVE_LEFT","accepted":true,"valid_for_ms":1500,"executed":false,"personal_validated":false,"experiment_only":true}
```

以上仅展示部分字段。完整字段以运行输出为准。

## 记录与故障处理

默认目录：`C:\Users\Administrator\Documents\NeuroStation\Datasets\RealtimeCommands\日期_时间_随机ID`。

- `raw_brainflow.tsv` / `raw_columns.tsv`：全 BrainFlow 行，连续增量保存，17 位数值精度；不按主机时间戳去重，不补点。
- `preflight.json`、`quality.json`、`session.json`、`manifest.csv`：真实设备预检、累计信号质量、会话结果、原始文件校验信息。
- `commands.ndjson`：指令输出；事件日志同时保留被拒绝或过期预测，便于解释 UNKNOWN。
- `command_events.ndjson` / `command_frames.ndjson`：指令事件、屏幕校对报告和逐帧记录；`command_manifest.json` 是独立指令清单，不改写原始 manifest。
- `capture.stderr.log` / `model.stderr.log`：采集与模型子进程错误。

如果屏幕校对通过、按 Enter 后仍出现采集错误，应查看具体故障阶段与端口。实时采集在预检选定的端口上最多握手三次，瞬时握手失败时等待 0.5 秒重试；不会重新扫描其他端口。错误消息及停止后的状态保留具体原因和采集日志路径，采集失败时不启动刺激。

包号缺失、重复、乱序、非有限值、平线、饱和会阻断推理窗口；恢复后必须重新累积完整连续窗口。超过 1 秒无新采样会停止沿用旧指令，模型结果超过 2 秒被拒绝。设备长时间断流或显示时序失败会终止当前会话。程序关闭时先停止和封存记录。

## 当前验证范围

软件版本与配置使用正式状态，但不代表当前个人模型有效。当前公开模型在既有个人迁移测试中未通过；历史失败结论及默认禁用标志保持原值。输出可能偏向某一类别，即使置信度很高也不能据此判定意图识别正确。

自动测试使用 fake 设备和合成消息验证连续采样、断流、停止、时序门控和记录机制。公开脑电测试只验证真实模型与指令输出链路。真实头盔佩戴、屏幕呈现和个人实时识别准确率，需要本人的真实会话另行测量。屏幕校对解决呈现时序检查；个体校准/训练解决模型对本人数据的适配，两者用途不同。
