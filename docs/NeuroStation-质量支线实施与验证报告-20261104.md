## 4. 接口、统计和安全语义

### 4.1 原始数据与水位

- 内部区间为零起始 `[start, stop)`；旧指令 `sample_end` 保持包含末点，进入质量门控时显式 `+1` 适配。
- 接收顺序不等于硬件无丢包。原包号/时间戳保留，不删重复点、不补零、不猜测丢失样本。
- `.npy` 原始块与 `blocks.jsonl` 构成可校验记录；`seal.json` 说明封存状态。缺 seal、坏链、孤立块或未完成尾部不能当完整会话。
- `assessed` 是连续已评估前缀，不能跨过失败/积压区间直接跳到最新数据。实时质量结果中的水位是提交该块时的快照；最终水位以封存文件为准。
- 质量队列超时可封存原始数据，质量部分保留未完成；保存错误不能继续宣告正常记录。

### 4.2 分母与标签

`all` 为实际有记录的试次标识。计划但没有事件的试次进入账本，并单列 `planned_without_events`，**不混入已记录试次的接受率分母**。旧会话未给出合法计划数量时不推测完整计划。

质量通过、模型接受与拒绝是不同集合；FFT 获胜频率不是模型接受。准确率还需对应标签和可评分结果；无标签、空分母返回 null。协议呈现目标不是注视证明，人工注视标签不是眼动仪测量。连续重叠窗口的指令记录不是独立试次准确率。

### 4.3 处理及指令

处理身份绑定配置、实现文件哈希及数值库版本；配置/流段切换重置因果状态、质量历史和旧代次待返回预测。原模型的权重、前处理和四份绑定源码保持不变，模型始终接收原有原始窗口，不接收新增显示带通结果。

SELECT 被接受一次后锁定。仅**被接受的 MOVE_LEFT/MOVE_RIGHT**或新会话重新布防；UNKNOWN、拒判、超时不能重新布防。本支线没有增加键鼠、执行器、串口控制动作。
