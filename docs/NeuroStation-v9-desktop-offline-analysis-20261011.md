## 结果含义

- 原始、传统滤波与v9三个轨道使用同一会话、同一试次窗口。传统参数预先固定为50Hz/Q30陷波及4阶1–45Hz带通，离线零相位计算，未根据此次结果搜索参数。
- 波形显示对同一短段各轨分别去均值，三个轨道共用幅值尺度；去均值仅用于显示。数值单位与电极位置尚未独立核验。
- v9仍使用既有250Hz分支进行个人Cyton迁移探测；报告保持 `source_domain=personal_Cyton`、`source_domain_validated=false`、`production_validated=false`。
- FFT是单独的透明基线，结果页显示呈现目标匹配数。没有注视标注时，不将该数字称为已验证的注视准确率。
- 非有限或平直输入不通过插值恢复。传统滤波/识别不可处理时显示不可用原因，冻结v9自身保留窗口策略继续适用。
- 没有干净成对EEG参考，频段功率变化、运行成功和协议呈现目标匹配都不能独立证明真实降噪效果或生理信号恢复。
