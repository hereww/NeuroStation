## 结论

当前版本可标记为：**NeuroStation 1.0 / Cyton 真实采集入口已收敛 / Windows standalone 非硬件验收通过**。

工作站已经形成 Cyton 真实采集链路：中文优先 PySide6 工作站、SSVEP 采集应用入口、硬件预检、独立 Cyton worker、会话文件、事件、帧时序和质量日志、数据集导航，以及 OpenBCI GUI 锁定源码和中文 overlay 的受管启动。生产入口拒绝 Synthetic、Demo 和 Preview 采集；Cyton 默认使用 CH1–CH8 自动板卡映射，实际电极位置仍由实验人员审核。

当前版本**不能**标记为“Cyton SSVEP 正式候选版”或“三平台 beta 发布版”。原因是实际 Cyton 硬件、photodiode/TTL 光学时序、Linux/macOS 原生构建和安装器人工验收尚未有本机证据。

## 运行方式

启动工作站：

```powershell
.\.venv\Scripts\python.exe workstation.py
```

启动独立 UI：

```powershell
.\.venv\Scripts\python.exe -m apps.workstation_ui.main --dataset-root "$env:TEMP\NeuroStationDemo"
```

启动已打包 Windows 版本：

```powershell
.\dist\NeuroStation.dist\workstation.exe
```

运行不打开串口的预检：

```powershell
.\dist\NeuroStation.dist\workstation.exe --diagnostics
```

运行真实 Cyton 前，先创建并审核正式通道表，然后执行：

```powershell
Copy-Item configs\channel_config_v1_template.json configs\channel_config_v1.json
python run_ssvep_session.py --channel-config configs\channel_config_v1.json --validate-only
python check_cyton_live.py --port AUTO --seconds 15
```

## 未完成门槛

1. H-01～H-07：需要 OpenBCI Cyton、USB dongle、实际 8 通道接线和三平台测试机；
2. T-01～T-03：需要实际显示器刷新率报告和 photodiode/TTL 仪器，软件逐帧日志不能替代物理测量；
3. D-01～D-07 的 Linux/macOS 列：需要对应系统原生构建、安装/升级/卸载和人工布局验收；
4. OpenBCI GUI 完整中文化：当前为首批核心 overlay，仍需按 `integrations/openbci_gui/I18N_ZH_CN.md` 扩展到全部用户可见页面；
5. 正式发布：仍需签名、notarization、安装器、SBOM 和第三方许可证清单。

## 放行规则

- A 系列全部通过：可作为功能版本；
- 对应平台 D 系列全部通过：才可发布该平台 beta 安装包；
- H 与 T 系列全部通过：才可标记为 Cyton SSVEP 正式候选版；
- 生产入口不得生成 Synthetic、Workflow Demo 或 Full-screen Visual Preview 数据；历史模拟会话只能只读展示，不得作为真实 EEG 使用；自动 Cyton 通道映射也不得被解释为电极位置识别。
