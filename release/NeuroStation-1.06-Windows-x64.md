# NeuroStation 1.06 Windows x64

- Product version: `1.06`
- Semantic version: `1.0.6`
- Build date: `2026-11-19`
- Intended release tag: `v1.0.6`

## 本版更新

- 从侧栏「脑电信号分析」选择当前采集、历史会话或合成演示。实时页面在收到数据后显示波形。历史会话按已有文件提供回放和报告。
- 可按通道查看原始与滤波波形、功率谱和频带占比。合成演示使用已标注的测试信号，可用于离线体验分析流程。
- 实时通道预览与校准测试分开。更改串口、电极位置或参考接线后会清除对应测试结果。采集保护也会识别已有的增量录制文件。

## 使用

解压 `NeuroStation-1.06-Windows-x64.zip`，运行 `NeuroStation.dist\workstation.exe`。正式采集沿用 Cyton 设备握手、通道检查、显示时序预检和光敏风险确认。实机采集质量需按现场条件验收。
