# NeuroStation 1.04 Windows x64

## Release information

- Product version: `1.04`
- Semantic version: `1.0.4`
- Build date: `2026-10-02`
- Release form: Windows standalone portable build
- Target system: Windows 10/11 x64
- Intended release tag: `v1.0.4`

## New in 1.04

- Dataset renaming is available from the dataset browser. Renames update session metadata, preserve left/right-eye suffixes, and validate names and collisions before changing files.
- Dataset tables can be opened with LibreOffice Calc, with clearer messages when spreadsheet applications or source files are unavailable.
- A standalone source-side display calibration tool, `scripts/calibrate_ssvep_display.py`, checks left/right half-screen geometry, the always-lit center divider, and measured presentation cadence without opening an EEG acquisition session.

## Improved in 1.04

- SSVEP rendering uses GPU/VSync presentation and frame-swap timing to improve stimulus scheduling and onset/offset auditing.
- Frame-timing reports include effective refresh rate, cadence review, frame intervals, and dropped-frame information. Stimulus timing metadata remains available with the recorded session.
- Retains primary-display half-screen stimulation, mandatory eye-side selection, the full virtualized raw-data preview, and backward compatibility with older datasets.
- Synchronizes product metadata, Windows executable metadata, bilingual UI titles, packaged version files, SBOM, and GitHub release configuration at `1.04 / 1.0.4`.

## Included

- PySide6 desktop workstation with Chinese and English UI;
- OpenBCI Cyton real-hardware acquisition and four-frequency SSVEP workflow;
- bundled OpenBCI GUI runtime, hardware preflight, channel configuration validation, session metadata, and quality reports;
- OpenBCI recording import, offline FFT analysis, SciPy denoising, diagnostics, and dependency SBOM;
- portable `NeuroStation.dist` directory and `NeuroStation-1.04-Windows-x64.zip` archive.

## Verification boundaries

Desktop unit/UI tests, UI scale checks, and packaged launch/diagnostic checks validate software behavior only. They do not replace Cyton hardware-in-the-loop testing, monitor refresh/photodiode or TTL measurements, long-duration stability testing, or clinical-device validation. GPU/VSync timing is not proof of optical stimulus onset. Display calibration must be performed on the actual experimental monitor before acquisition.

This software is for research and teaching validation, not medical diagnosis. No synthetic EEG is generated by release verification.

After extracting the archive, run `NeuroStation.dist\workstation.exe`. No separate Python installation is required. Keep existing acquisition data outside the portable application directory when replacing an older build.
